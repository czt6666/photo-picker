远程相册：留言、下载、删照片，还有一批界面细节。

## 新功能

- **留言**：远程相册里每张照片都能留言，有链接的人都能写，不用填名字。别人的留言实时出现，格子上显示条数。自己的留言自己能删，相册创建者能删所有留言。看大图时，手机点底栏的气泡，电脑在右侧面板
- **下载**（网页版）：大图里多了下载按钮，下的是长边 1600 像素的图，文件名和原图一样。手机上会弹出系统分享面板，能直接存进相册
- **从相册里删除**：相册创建者可以选中照片，从远程相册里删掉（菜单和右键都有）
- **导出可以「移动」**：导出时可选移动（默认）或复制。同一块盘上直接挪，跨盘先复制再删原文件，不会覆盖同名文件

## 改动

- 工作目录菜单：远程相册用云朵图标，后面的小垃圾桶是从列表里移除（线上相册还在）。创建者有红色的「删除该相册」，都会先弹窗确认
- 去掉菜单里的「分享」「改名」「从列表中移除」「刷新」
- 顶栏：工作目录按钮和刷新按钮放一起，和侧栏同宽；分享按钮挪到标题左边
- 远程相册没有星级，大图里不再显示那排星星

## 安装

- **macOS**：下载 `.dmg`。没有苹果公证，第一次打开请在“应用程序”里右键 → 打开 → 打开
- **Windows**：下载 `_x64-setup.exe` 运行。没有代码签名，SmartScreen 提示时点“更多信息 → 仍要运行”
