这一版的重点是**远程相册**：和模特（或任何人）一起在手机上挑片，星标实时同步，挑完在电脑上导出原图。

## 新功能

- **远程相册**：工作目录菜单里「创建远程相册」，选一个文件夹就上传。只传缩小的 JPG（长边 1600 像素，约 0.1MB 一张），RAW 和原图都留在你电脑上；上传在后台跑，右下角有进度
- **分享链接**：建好自动弹出链接（顶栏「分享」也能随时打开），对方打开就能看，不用装 App、不用登录、不问名字
- **实时同步**：谁加星、取消，其他人一秒内就能看到
- **网页版**：链接打开的就是 PhotoPicker 本身，电脑、平板、手机浏览器都能用
- **手机上学 iPhone 的“照片”**：方格铺满，双指捏合改每行几张；点开照片从格子里放大出来；左右滑动跟手翻页，前后照片预先加载；底部只有星标和信息两个按钮，往上推照片看信息，往下拖回到网格
- **导出原图**：在桌面版打开远程相册，⌘E 导出星标照片，复制的是本机原图（可带同名 RAW）

## 改进

- 工具栏图标换成线条图标，界面文字更短
- 工作目录只在顶栏切换

## 安装

- **macOS**：下载 `.dmg`。没有苹果公证，第一次打开请在“应用程序”里右键 → 打开 → 打开
- **Windows**：下载 `_x64-setup.exe` 运行。没有代码签名，SmartScreen 提示时点“更多信息 → 仍要运行”
