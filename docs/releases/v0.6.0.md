星级能写进照片文件了，Lightroom 等软件直接读得到；远程相册也能打星级，还能按星级筛选。

## 星级

- **写进照片文件**：打的 1～5 星同时写进照片自己的 XMP 元数据，Lightroom、Bridge、Capture One 打开就能看到。JPEG 写在文件里；RAW 写在同名的 `.xmp` 文件里，原片一个字节都不动
  - 只改星级这一项，EXIF、色彩配置、Lightroom 的修图参数都原样保留；文件的修改时间不变，按时间排序不会乱
  - 个别文件写不进去（只读、文件损坏）时会提示，选片里照样记着星级
- **按星级筛选**：电脑上星标筛选挪到了底栏，旁边新增五颗星。点第 n 颗星就只看 n 星及以上的照片，再点一下取消
- **远程相册也能打星级**：1～5 星，相册里所有人共用一份，实时同步

## 改动

- 导出或移动照片后，星标和星级跟着照片到新文件夹，新文件也写上星级（移动时原文件夹的记录一并清掉）
- 修复：格子上的留言数和星级叠在一起

## 安装

- **macOS**：下载 `.dmg`。没有苹果公证，第一次打开请在“应用程序”里右键 → 打开 → 打开
- **Windows**：下载 `_x64-setup.exe` 运行。没有代码签名，SmartScreen 提示时点“更多信息 → 仍要运行”
