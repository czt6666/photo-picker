第一个正式版，macOS（通用版，Apple 芯片和 Intel 都能用）和 Windows（x64）都有安装包。

## 能做什么

- **选工作目录就能看**：⌘O / Ctrl+O 或把文件夹拖进窗口，子文件夹自动成为相册，不用导入、不建图库
- **滚轮翻图不卡**：慢拨一格一张，触控板推多远翻多远；放大看对焦时翻页保持倍数和位置
- **星标 + 星级**：空格加星标（筛选、导出只看它），1～5 键打星级，两者互不影响，和 Lightroom 一样
- **RAW+JPG 合成一张**：同名文件一起打星、一起导出
- **星标筛选**：侧栏一键汇总所有相册的星标，再点一次（或 Shift+S）关掉
- **相册多也好找**：按年份分组可折叠，相册多时有筛选框；网格滚到底接着显示下一个相册
- **导出**：当前相册的星标或选中的照片，原图复制，可勾选同名 RAW
- **中文 / English**：默认跟随系统，在设置（⚙ / ⌘,）里切换
- 兼容 Picasa 的 `.picasa.ini`，Picasa 打过的星直接能看到

## 安装

- **macOS**：下载 `.dmg`。没有苹果公证，第一次打开请在“应用程序”里右键 → 打开 → 打开
- **Windows**：下载 `_x64-setup.exe` 运行。没有代码签名，SmartScreen 提示时点“更多信息 → 仍要运行”
