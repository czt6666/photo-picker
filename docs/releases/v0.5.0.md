远程相册的留言更好用了：带名字、未读提醒、实时横幅；动画换成 iPhone 的手感。

## 留言

- **名字**：留言时带上名字。第一次随机起一个（比如「好奇的水獭」），之后一直用它，自己改了才变
- **未读提醒**：别人留的、你还没看过的留言标成红色。打开相册时，这些照片单独放在最上面的「未读留言」一栏，看完就回到原来的位置
- **横幅通知**：有人留言时顶部弹出横幅，点一下直接跳到那张照片的留言。重新打开相册时，会提示离开期间有几条新留言
- 留言输入框重新设计，更简洁

## 改动

- 动画统一成 iPhone 系统动画的曲线；手机上的留言、信息面板可以按住往下拉
- 从下面的相册往上滑，能接上前面的相册
- 网页版发新版后会自动刷新，不会再卡在旧页面（微信里也一样）
- 去掉大图的 1:1 按钮（Z 键、双击照旧能放大）、网页版的全屏按钮、底栏的加星标按钮
- 远程相册菜单暂时不能删除整个相册
- 修复：看留言时信息按钮也跟着亮

## 安装

- **macOS**：下载 `.dmg`。没有苹果公证，第一次打开请在“应用程序”里右键 → 打开 → 打开
- **Windows**：下载 `_x64-setup.exe` 运行。没有代码签名，SmartScreen 提示时点“更多信息 → 仍要运行”
